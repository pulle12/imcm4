## Projektstruktur (typisch)

Die meisten Projekte sind gleich aufgebaut:

- `index.html`
- `script.js`
- `style.css`

Spezialfall:

- `Projekt14_jQuery_Aktien-Watchlist` enthaelt zusaetzlich:
	- `jquery-4.0.0.min.js`
	- `chart.js`

## Hinweise

- Nach Projekt 14 wurde vom alten Vue-Tutorial (Scrimba) auf ein neues Tutorial gewechselt.
- Teile des Materials (Intro-to-Vue-3) liegen in separaten Ordnern oder als Submodule/Startdateien vor.
- Nicht alle Entwicklungsstände und Commits aus externen/abgetrennten Arbeitsordnern sind in diesem Haupt-Repository enthalten.

## Lokales Starten

Ein Projekt oeffnen:

1. Gewuenschten Projektordner auswaehlen.
2. `index.html` im Browser oeffnen.
